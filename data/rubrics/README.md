# 逐 skill 动态评分标准(rubrics)

每个被 lamarck 观察的 skill 一个文件:`<skill>.md`。尺子与 skill 共同进化,
全部纳入 git 版本控制(diff 可查、可回滚)。

## 文件结构(两层)

```markdown
# rubric: <skill-name>

## 行为标准(动态层,从真实证据结晶)
- [R1] <什么算好输出 / 什么禁止> (出处: ledger <日期> <outcome>×<次数>; 场景: <标签>; 引用: <次数>)

## attic(已淘汰,不删除)
- [R0] <旧标准> (淘汰原因: 场景消失/被 R3 取代; 淘汰日期)
```

## 规则

- **入册门槛 n=1**:用户纠正一次即可结晶为一条标准(rubric 只是评估视角,
  不改 skill 行为;改 skill 文件仍需 ≥2 证据)。
- **无出处禁止写入**:每条标准必须引用 ledger 条目,防评估者拍脑袋立法。
- **淘汰进 attic**:过时标准标注原因移入 attic 段,不物理删除。
- **场景标签**:评估时只启用与本次调用场景匹配的条目,不匹配不扣分。
- **冷启动**:skill 无历史时退回结构兜底检查(失败分支显式、有反例黑名单、
  无软话术、引用路径可达),行为标准从第一条证据开始积累。
